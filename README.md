# 🗄️ Online Library Server

Серверна частина (REST API) для курсового проєкту **"Online Library"**.
Забезпечує обробку запитів, авторизацію користувачів та взаємодію з базою даних. Побудовано на архітектурі MVC з використанням **Node.js** та **Express**.

## 🔌 Основні можливості API

Сервер надає ендпоінти для роботи з даними у форматі JSON:

### Auth (Авторизація)
* `POST /api/auth/register` - Реєстрація нового користувача.
* `POST /api/auth/login` - Вхід у систему (повертає JWT токен та дані користувача).

### Books (Книги)
* `GET /api/books` - Отримати список всіх книг (підтримує фільтрацію).
* `GET /api/books/:id` - Отримати детальну інформацію про книгу.
* `POST /api/books` - Додати нову книгу (для адмінів).

### User (Користувач)
* `GET /api/user/favorites` - Отримати список обраного.
* `POST /api/user/favorites` - Додати/Видалити книгу з обраного.

---

## 🛠 Технологічний стек

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MySQL 
* **Security:** bcrypt (хешування паролів), jsonwebtoken (JWT), cors

---

## 🗃️ Налаштування Бази Даних

При першому запуску сервер автоматично перевіряє наявність необхідних таблиць.
Основні таблиці:
1.  **users** - дані користувачів.
2.  **books** - каталог літератури.
3.  **favorites** - зв'язок "багато-до-багатьох" між користувачами та книгами.
